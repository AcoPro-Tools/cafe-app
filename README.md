# ☕ نظام منيو وطلبات الكافيه الذكي (QR Cafe System)

نظام متكامل واحترافي لإدارة طلبات الكافيهات والمطاعم عبر رموز الاستجابة السريعة (QR Code)، مبني بأحدث تقنيات الويب الحديثة.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Framework:** Next.js (App Router) + TypeScript
- **Styling & UI:** Tailwind CSS + Lucide Icons + Google Font (Cairo)
- **Database & ORM:** SQLite + Prisma ORM
- **Authentication & Security:** Jose (JWT Sessions) + HTTP-Only Cookies + Bcryptjs + Next.js Middleware

---

## 🎨 هوية وثيم التصميم (Specialty Coffee Theme)

- **اللون الأساسي:** إسبريسو غامق (`#3C2A21`)
- **خلفية الصفحات:** كريمة دافئة (`#FAF6F0`)
- **اللون الثانوي والتمييز:** كراميل دافئ (`#C89D7C`)
- **دعم كامل للغة العربية والاتجاه (RTL) مع خط Cairo الأصيل.**

---

## 👥 حسابات التجربة السريعة (Demo Accounts)

تم تجهيز أزرار تسجيل دخول سريعة في صفحة `/login` للمراجعين لتعبئة البيانات والدخول فوراً:

| الحساب | البريد الإلكتروني | كلمة المرور | الصلاحيات |
| :--- | :--- | :--- | :--- |
| **مدير النظام (Admin)** | `admin@cafe.com` | `admin123` | شاشة الكاشير الحية + زر تبديل المخزون + لوحة إضافة وتعديل وحذف المنتجات بالكامل + الإحصائيات |
| **كاشير / باريستا (Cashier)** | `cashier@cafe.com` | `cashier123` | شاشة متابعة الطلبات الحية + تحديث الحالات + زر تبديل توفر الأصناف الفوري (متاح / نفذت الكمية) |

---

## 📱 صفحات وتجربة النظام

1. **قائمة المنيو للعميل (`/` أو `/?table=5`):**
   - تحديد رقم الطاولة تلقائياً من الرابط أو تغييره من الهيدر.
   - تصفح الأقسام (مشروبات ساخنة، باردة، حلويات) مع شريط بحث حي.
   - نافذة تخصيص المشروب (اختيار الحجم مع فارق السعر، السكر، نوع الحليب).
   - سلة منبثقة (Slide-over Cart) مع حساب صارم للأسعار في السيرفر وتأكيد توفر المخزون.

2. **شاشة تتبع الطلب والفاتورة الإلكترونية (`/order/[id]`):**
   - مسار تتبع حي لحالة الطلب (وصل للكاشير ➔ يتحضر في البار ➔ جاهز للتقديم).
   - تحديث تلقائي كل 4 ثوانٍ (Auto-polling) بدون تحديث الصفحة.
   - فاتورة إلكترونية مفصلة بالخيارات والإجمالي.

3. **لوحة تحكم الكاشير والإدارة (`/dashboard`):**
   - محمية بـ Middleware وخاصية RBAC.
   - **طلبات الكاشير الحية:** إمكانية بدء التحضير، تحديد الجاهزية، أو إنهاء الطلب.
   - **تبديل المخزون السريع (Quick Stock Toggle):** إيقاف طلب أي صنف بلحظة (نفذت الكمية) وتحديثه فوراً للمنيو.
   - **إدارة المنيو للأدمن:** إضافة أصناف جديدة، تعديل الأسعار والأحجام، وحذف الأصناف.
